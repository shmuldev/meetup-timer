- כפתורי התחלה, השהיה, המשך ואיפוס.
- בסיום, כפתור ״נושא חדש״ מתחיל דיון חדש מאפס.
- רווח: התחלה / השהיה. F: מסך מלא.
- הזמן ממשיך להימדד כשהלשונית ברקע; ההתראה מתעדכנת כשחוזרים.
- רענון העמוד מאפס את המדידה.

## בדיקה מקומית

```sh
python3 -m venv .venv
.venv/bin/pip install playwright
.venv/bin/playwright install chromium
.venv/bin/python check_timer.py
```

הבדיקה מקדמת שעון מדומה ומוודאת את תשע ההתראות, עצירה בסיום, התחלה מחדש, השהיה והמשך, איפוס, מקלדת ותצוגה בארבעה גדלים.
